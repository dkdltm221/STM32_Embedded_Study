# 오류 분석 및 해결 기록

실습 중 발생한 문제를 다른 날에도 재현하고 확인할 수 있도록 다음 항목을 기록합니다.

1. **증상과 오류 메시지** — 어떤 상황에서 어떤 오류가 나타났는지 기록합니다.
2. **환경과 재현 과정** — 프로젝트, 보드, 사용 도구와 재현 순서를 적습니다.
3. **원인** — 확인한 로그나 소스 위치를 근거로 남깁니다.
4. **해결 방법** — 어떤 설정이나 코드를 바꿨는지 기록합니다.
5. **검증 결과** — 빌드와 보드 동작에서 각각 확인한 항목을 적습니다.

파일 이름은 문제가 드러나도록 작성합니다. 예시로 `gpio-led-build-error.md`를 사용할 수 있습니다.

GPIO 실습 기록에 남긴 문제는 [핀 이름·ELF 파일 확인](../docs/gpio/gpio_led.md#코드-생성과-빌드)과 [외부 LED 지연 문제](../docs/gpio/gpio_led.md#문제와-핵심)에서 볼 수 있습니다.

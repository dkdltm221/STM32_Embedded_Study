# GPIO 입력과 스위치

2026-11-17 · NUCLEO-F411RE

## 1. 입력 모드에서 전압 읽기

GPIO를 입력 모드로 설정하면 외부에서 들어오는 전압을 논리 상태 LOW 또는 HIGH로 읽을 수 있다. STM32F411의 디지털 입력에는 슈미트 트리거가 있다. 입력이 올라갈 때와 내려갈 때의 판정 문턱이 다르므로 문턱 근처에서 작은 잡음으로 상태가 반복 전환되는 현상을 줄인다.

| 설정 또는 함수 | 역할 |
| --- | --- |
| `GPIOx_MODER` | 핀의 2비트 필드를 `00`으로 설정하여 입력 모드를 선택한다. |
| `GPIOx_PUPDR` | 외부 회로의 기본 상태에 따라 내부 풀업·풀다운을 선택한다. |
| `GPIOx_IDR` | 핀의 현재 논리 상태를 읽는다. 핀마다 1비트를 사용한다. |
| `HAL_GPIO_ReadPin()` | `IDR`의 지정 핀을 읽어 `GPIO_PIN_SET` 또는 `GPIO_PIN_RESET`을 반환한다. |

## 2. 스위치의 기본 상태

외부 스위치를 GND로 연결하고 풀업을 사용하면, 스위치가 열려 있을 때 입력은 HIGH이고 누르면 LOW가 된다. 이때 눌림은 하강 에지다. 반대로 스위치를 VDD로 연결하고 풀다운을 사용하면, 누를 때 입력이 LOW에서 HIGH로 바뀐다.

풀업이나 풀다운으로 스위치가 열렸을 때의 전압을 정한다. 기계식 접점은 한 번 눌러도 짧게 반복 전환될 수 있으므로 눌림을 한 번만 처리하려면 디바운싱이 필요하다.

## 3. 입력 전압과 실습

NUCLEO-F411RE의 3.3 V 로직과 연결할 때는 데이터시트의 입력 전압 범위와 `VIL`·`VIH` 조건을 확인한다. 일부 핀은 `FT`로 표시되며 지정된 조건에서 5 V 입력을 허용한다. 5 V 허용 여부는 핀과 모드에 따라 다르고, 아날로그 모드에서는 5 V 허용이 적용되지 않는다.
